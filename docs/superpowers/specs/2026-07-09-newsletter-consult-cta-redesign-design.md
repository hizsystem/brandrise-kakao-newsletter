# 데일리 뉴스레터 — 상담 전환형 토스풍 리디자인 설계

**작성일**: 2026-07-09
**범위**: 웹 뉴스레터(v2, `html_formatter_v2.py`)의 디자인 개편 + 브랜드라이즈 무료 상담 CTA 강화
**대상 리포**: hizsystem/brandrise-kakao-newsletter

## 1. 목표

브랜드라이즈 무료 상담 신청 전환을 높인다. 전환은 **웹 페이지**에서 일어난다(카톡은 웹으로 유도하는 관문). 이를 위해 웹 뉴스레터를 토스(Toss) 어법의 모바일 우선 디자인으로 개편하고, 상담 CTA를 상단 진입점 + 하단 강한 전환 블록 2단으로 배치한다.

**우선순위**: 상담 CTA 강화(#1) > 디자인 개편(#3, CTA를 돕는 수단).

## 2. 비범위 (별도 세션)

- **자동화(#1)**: 화/수/금 특수 소스 URL 수동 갱신의 자동화 — 별도.
- **콘텐츠(#2)**: 브랜딩·마케팅 소식 위주로 수집 소스 재편 — 별도.
- 카톡 텍스트 버전은 이번 개편의 주 대상이 아님. 카피 톤 정합만 소폭 반영(§7).

## 3. 현황

- 웹 v2는 흰 배경 + 다색 그라디언트 카드 나열. 아이보스 기사는 개별 링크 없음(2열 썸네일 그리드, 클릭 불가). 이미지 톤이 기사마다 제각각(Gemini 생성).
- 상담 CTA는 맨 아래 다크 카드 1회(`BRANDRISE_CTA_HTML`), "살짝 공지드려요" 톤. 웹 버튼 링크가 `utm_source=kakao`로 박혀 웹 전환이 카톡으로 오집계됨.
- 폰트: Google Fonts Noto Sans KR.

## 4. 디자인 시스템 (토스 어법)

승인된 목업 기준. 강조는 한 곳(하단 CTA)에만 쓰고 나머지는 조용하게.

### 색 토큰
| 토큰 | 값 | 용도 |
|------|-----|------|
| `--card` | `#FFFFFF` | 카드 바탕 |
| `--ground` | `#F2F4F6` | 섹션·썸네일 바탕(토스 그레이) |
| `--ink` | `#191F28` | 본문 |
| `--ink2` | `#4E5968` | 인사말 |
| `--ink3` | `#6B7684` | 요약·보조 |
| `--gray` | `#8B95A1` | 라벨·캡션 |
| `--line` | `#E5E8EB` | 헤어라인 |
| `--accent` | `#3182F6` | 강조(토스 블루) |
| `--accent-d` | `#1B64DA` | 강조 그라디언트·호버 |
| `--accent-soft` | `#E8F1FE` | 아이콘 배경 |

### 타이포
- 폰트: **Pretendard** 1종. 굵기·크기만으로 위계(토스 방식). CDN 링크(jsdelivr Pretendard) + 시스템 폴백 `'Apple SD Gothic Neo','Malgun Gothic',-apple-system,sans-serif`.
- 한국어 줄바꿈: `word-break: keep-all` 전면. 제목 `text-wrap: balance`.
- 스케일(모바일 기준): H1 27 / 섹션 h2 19 / 카드 제목 15.5 / 인사말 15 / 요약 13 / 라벨 11.5–12, 대문자 letter-spacing.

### 레이아웃
- **모바일 우선**: 단일 컬럼 `max-width ~460px`, 데스크톱은 가운데 좁은 컬럼. 넉넉한 여백.
- 탭 타깃 확대: 상단 진입점 min-height 60px, 하단 버튼 풀폭 min-height 56px, 리스트 행 88px 썸네일.
- 카드 라운드 16–22px, 저채도 그림자.
- 라이트 단일 테마로 커밋(뉴스레터는 밝은 문서). Artifact 프리뷰에선 다크 배경 백드롭만 대응.

## 5. 페이지 구조

```
[브랜드바: Brandrise 데일리 · 날짜]
[헤더: eyebrow + H1 + 인사말]
[상단 상담 진입점 — 슬림 바 (첫 화면 노출)]
[오늘의 마케팅 뉴스 — 아이보스, 전체 썸네일 리스트(클릭 → 원문)]
[카테고리 헤드라인 — 뉴스럴]           (해당 요일)
[전시/팝업 — 헤이팝]                    (목)
[이번 주 뉴스레터 — 빌더조쉬/풋풋/캐릿/까탈로그] (화/수/금)
[오늘의 아티클 — 롱블랙 (히어로 이미지 카드, 현행 유지)]
[★ 하단 메인 상담 CTA — 풀블럭 토스 블루]
[푸터]
```

목업은 일일 코어(아이보스+롱블랙+CTA)만 렌더링했다. **구현 시 뉴스럴·헤이팝·스티비·빌더조쉬 섹션도 동일 디자인 언어(토스 토큰·타이포·여백)로 재스타일링한다.**

## 6. 컴포넌트 명세

### 6.1 아이보스 뉴스 리스트 (핵심 변경)
- 2열 그리드 → **전체 균일 썸네일 리스트**(1위 히어로 없음). 행 = 88px 라운드 썸네일(좌) + 순위 배지 + 제목(2줄 클램프) + 요약(1줄 클램프) + `›`.
- **행 전체가 `<a href="{item.url}">`** — 클릭 시 원문. `item.url`은 아이보스 수집기가 이미 제공(기사별 외부 링크, 없으면 아이보스 글 URL 폴백; `collectors/iboss.py:86`).
- 순위 배지: 아이보스 원 게시 순서 표기(반투명 다크 + 흰 숫자).
- 호버 배경 틴트 + `›`로 탭 가능 어피던스.

### 6.2 상단 상담 진입점 (신규)
- 인사말 바로 아래 슬림 바. 아이콘 + "브랜딩·마케팅, 어디서부터 막막하다면 / 30분 무료 상담으로 방향부터 잡아보세요" + "상담 →". 조용한 톤, 강조색 최소.
- 링크: 상담 폼 + `utm_content=top`.

### 6.3 하단 메인 상담 CTA (강화)
- 풀블럭 토스 블루 그라디언트(`--accent`→`--accent-d`), 흰 텍스트, 풀폭 흰 버튼. 페이지에서 유일하게 강조를 다 쓰는 지점.
- 카피(확정, 줄바꿈 고정):
  - 라벨: `브랜드라이즈 무료 상담`
  - 헤드라인: `혼자 고민하지 마세요.`
  - 본문: `브랜드 진단부터 지금 당장 해야 할 우선순위까지,` ↵ `30분 무료 상담에서 함께 정리해드려요.`
  - 증거: `이미 **수십 개 브랜드**가 상담받았습니다.` ↵ `내 브랜드처럼, 함께 고민하는 팀원의 마음으로 봅니다.`
  - 버튼: `30분 무료 상담받기 →`
  - 미세문구: `스타트업 대표·마케팅 담당자를 위한 30분`
- "수십 개"는 규모감 표현만. 정확한 수치·후기·긴박감(마감/한정)은 근거 없으므로 넣지 않는다.
- 링크: 상담 폼 + `utm_content=bottom`.

### 6.4 롱블랙 (유지)
- 현행 히어로 이미지 카드 유지(사용자 확인). 토큰만 새 팔레트에 맞춤.

## 7. 이미지 파이프라인 (토스풍 통일)

- **문제**: 현재 아이보스 이미지가 기사마다 스타일 제각각.
- **변경**: `image_gen.py`의 아이보스 이미지 생성 프롬프트를 **일관된 토스풍 플랫 일러스트** 스타일로 교체. 고정 스타일 접미사(플랫 벡터, 소프트 라운드, 블루 `#3182F6` 액센트, 오프화이트 `#F2F4F6` 배경, 텍스트/글자 없음, 단일 중심 개념, 정사각 1:1) + 기사별 주제만 가변.
- 썸네일 규격: 정사각(1:1), 리스트에서 88px 표시.
- 롱블랙·스티비·헤이팝은 실사 OG 이미지 유지(별도).

## 8. 전환 추적

- 상담 폼 링크 UTM 정리:
  - 웹: `utm_source=web&utm_medium=cta&utm_campaign=brandrise&utm_content={top|bottom}`
  - 카톡: `utm_source=kakao`(현행 유지).
- 상단/하단 `utm_content`로 어느 위치가 전환되는지 학습. Google Form 응답 + GA에서 채널·위치별 구분 가능.

## 10. 결정 사항 (2026-07-09 확정)

1. **폰트**: Pretendard **CDN 링크**(jsdelivr) + 시스템 폴백. 자가 호스팅 안 함.
2. **카톡 텍스트 CTA 카피**: 새 톤으로 정합(§9 `formatter.py`). UTM은 kakao 유지.
3. **강조색**: 토스 블루 `#3182F6` 확정.
4. **순위 배지**: 유지(아이보스 원 게시 순서).

## 11. 성공 기준

- 웹 상담 폼 유입이 채널(web/kakao)·위치(top/bottom)로 분리 집계된다.
- 모든 요일(섹션 조합)에서 토스 디자인 언어가 일관되게 렌더된다.
- 모바일에서 썸네일 리스트가 스캔 가능하고 뉴스 카드 클릭이 원문으로 연결된다.
- 하단 CTA가 페이지의 유일한 강조로 시선을 모은다.
